# Pictures needed

162 of the 202 storybook pages have their own drawing of their story. These 40 still borrow one of the 60 cover drawings (shown in brackets) until theirs is drawn. The number is the page's place in the whole set, counting from Genesis page 1.

**To add drawings:** draw them in the same style (bold black outlines, white inside, no shading), one to a box with the page's number in the corner, and save the sheet anywhere. Add the sheet to `GRIDS` in `tools/cut_scenes.py`, run it on the folder of sheets, then run `tools/trace_pictures.py`, point each page at `scenes/<number>` and run this script again.
